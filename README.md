# YS-Lite-arm

远山 Lite 六轴机械臂开源资料：上位机控制程序与结构件 3D 打印模型。

```text
host-app/    上位机（Python + tkinter，Windows）
model/       结构件模型（STL）
BOM/         物料清单（采购参考，型号 / 规格 / 数量，不含价格）
```

## 上位机

```bash
python host-app/servo_control.py
```

- 连接：USB-TTL 单线半双工，默认 `115200-8-N-1`，串口号在界面里选
- `servo_control.py`：主程序。六轴角度 / PWM 双向换算下发、状态监控、参数设置、急停释放力矩与恢复；网页仿真的 WebSocket 桥也在这个文件里（先前是独立的 `sim_bridge.py`）
- `arm_config.json`：关节参数（行程、PWM 限位、方向、速度、补偿、归零位），需与主程序同目录

无第三方依赖，串口经 Win32 API 实现，Windows + Python 3 即可运行。

## 网页仿真联动

界面上「网页仿真」一栏点「打开网页仿真」，程序会在本地起两个服务并自动打开浏览器：

- `ws://127.0.0.1:8765` — 上位机与页面之间的角度通道
- `http://127.0.0.1:8766` — 网页仿真的构建产物（由程序内建静态服务提供）

「联动」下拉框决定方向（**默认关闭**，需要手动选）：

| 模式 | 行为 |
|---|---|
| 关闭 | 只保持页面连接，不传角度 |
| 真机 → 仿真 | 把舵机实时角度推给页面，页面只跟随 |
| 仿真 → 真机 | 拖动页面里的关节，驱动真实舵机 |

「仿真 → 真机」按电源电流做了保护：一次最多 2 路轴同时运动，逐路依次下发（间隔 80 ms），速度固定为 45°/s 且单次动作不超过 700 ms。六轴一起启动会把电压拉低、导致总线超时，所以刻意压着走。

联动开启（模式不是「关闭」）时，网页里的「当前末端逆解姿态」按钮会被自动禁用——一次逆解会把六轴同时推到新姿态，联动状态下等于直接让真机做大幅度联动，电流冲击很大。关掉联动即恢复可用。

协议：上位机下发 `{"type":"motor_angles","payload":{"angles":[6 个值]}}`，页面回传 `{"type":"sim_angles","payload":{"angles":[6 个值],"t":秒}}`。前 5 个值是关节角度，第 6 个是夹爪开合量 0–400。

## 模型

均为二进制 STL。

- `model/3D打印.stl` — 结构件打印模型，可直接导入切片软件打印
- `model/装配.stl` — 整机装配体，用于核对安装位置与干涉
